## Deck plan (as the articles describe it)
Temur artifact tokens. Gimbal's power scales with differently named artifact tokens you control and it gives trample, so the deck wants many distinct token types and big artifact creatures. The upgrades add token makers, mana rocks and artifact card draw and strip Planechase pieces.
## Weaknesses the articles name
- Light on card draw, ramp and synergy (1).
- Has no white, so lacks common token makers and duplicators (2).
- Does not tie into March of the Machine themes; mana base could be better (3).
- Planechase cards add little to the Commander deck (1, 3).
- Curve is expensive (1).

## Consensus one-liner
Replace Planechase and slow filler with cheap rocks, card draw and as many distinctly named artifact token makers as possible.
