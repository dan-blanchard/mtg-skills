# Sultai Arisen — Teval, the Balanced Scale
## Sources
1. Tarkir: Dragonstorm Sultai Arisen Precon Upgrade — Card Kingdom Blog — https://blog.cardkingdom.com/tarkir-dragonstorm-sultai-arisen-precon-upgrade-review/ — 2025-03-26 — $50 target (8 swaps)
2. Sultai Arisen Upgrade Guide: 19 Easy Changes, Steve Vrooman — Draftsim — https://draftsim.com/sultai-arisen-upgrade-guide/ — 2025-03-29 — no budget stated (precon $132)
Note: Draftsim builds around Kotis; Card Kingdom and Draftsim comments both prefer Teval as commander. Draftsim's list is written for the Kotis build.
## Deck plan (as the articles describe it)
A graveyard deck that pays off cards leaving the graveyard: self-mill, land and creature recursion, zombie/druid tokens, landfall. Teval loads, recurs lands and pays off graveyard exits; Kotis is seen as better in the 99. Card Kingdom upgrades by adding recurrable utility lands; Draftsim adds more recursion engines.
## Weaknesses the articles name
- Mana base is tough; wants better duals and tri-lands (2)
- Too many goals; needs focus (2)
- No answer to graveyard hate such as Rest in Peace (2)
- Weak or conflicting cards (Necropolis Fiend vs delve, Forbidden Alchemy cost) (2)
- Kotis takes setup and pays off only creatures (1)
- Situational/expensive cards: Floral Evoker, Welcome the Dead, Colossal Grave-Reaver, Steward of the Harvest (1)

## Consensus one-liner
Upgrade the mana base with recurrable utility and dual lands and swap generic value cards for dedicated graveyard/recursion engines.
