# Precon tuner re-read: the reviewer brief

The brief each full re-read's reviewers follow (a Sonnet subagent per slice of
the 55 decks). The "Do NOT flag" list is the settled verdicts, each checked
against card text, a count or a measurement; extend it when a pass settles a
new flag. Paths are relative to the repo root. Make the review file with
`docs/plans/precon-audit/deck_report.py <misses.json> <Deck> ...` (`DECK_ROOT` for the held-out and
fresh sets) and point the reviewer at it.

You are a Commander deckbuilder reviewing a deck tuner's swap proposals against published upgrade guides. Read the file named below whole with the Read tool (10 to 13 deck blocks).

Each block has PLAN / WEAKNESSES / CONSENSUS (from the guides), the guides' recommended cuts and adds, then "-- tuner swaps:" lines `cut -> add | kind | reason`.

Flag only swaps a careful deckbuilder would call a STRUCTURAL mistake of the tuner (something a rule keyed on card text could catch). Flag-worthy: an add dead or near-dead in this deck (needs a resource, tribe, card type or counters the deck lacks — say what you counted); an add outside the commander's color identity; an add that hurts the deck's own plan on balance (a symmetric effect that also hits opponents is weighed, not flagged); a cut of a card that supplies what the commander's own text asks for when its add supplies nothing the commander asks for; a clear downgrade at the same job; a card counted for a job it can't really do; two swaps that contradict each other. For board-wipe swaps: whether the cut sweep was one-sided in THIS deck (it spares most of the deck's own creatures and the commander) and the add is not.

Do NOT flag (settled, each checked against card text and measured):
1. A theme card traded for a more-played theme card of the same kind on play-rate alone, including one supplying a different one of the commander's needs.
2. A removal / draw / ramp / wipe card traded for a more-played staple doing the same job.
3. A cut the guides themselves also name.
4. A strong body cut by a "role short" / "upgrade" page when the add does a real job.
5. An add on the commander's plan even if not in the guides' list.
6. A tribal deck's member count falling as weak members go for payoffs, outlets or removal.
7. A full job slot (removal, draw, ramp) moving onto a permanent theme card.
8. A cheaper add chosen because the deck's budget ran out; a deck making fewer than 30 swaps.
